# Peak Tech IT Solutions

A cutting-edge, high-performance web platform for **Peak Tech IT Solutions** — specializing in enterprise cloud architecture, automated Kubernetes infrastructure, Zero-Trust security, and production-grade applied AI systems.

![Peak Tech Hero Preview](public/hero-preview.png)

---

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, React 18, Server & Client Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with customized cyber-dark design system
- **Typography:** [Baloo 2](https://fonts.google.com/specimen/Baloo+2) & JetBrains Mono via Google Fonts
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Visuals & Canvas:** Interactive HTML5 Aether Flow particle constellation with real-time cursor physics
- **Icons:** [Lucide React](https://lucide.dev/)
- **UI Architecture:** [shadcn/ui](https://ui.shadcn.com/) component structure

---

## ✨ Features

- **Interactive Aether Flow Hero:** Dynamic particle constellation engine with real-time cursor repulsion and luminous straight-line connections.
- **Enterprise Solutions Showcase:** Modular presentations for Cloud Infrastructure, DevOps & SRE, Applied Generative AI (RAG), and Cybersecurity.
- **Organic Asymmetric Visuals:** Signature leaf-shaped photo frames and frosted glassmorphism cards.
- **Interactive Consultation Booking Modal:** Direct client inquiry and strategy session scheduler.
- **Responsive & Dark-Themed:** Tailored cyber-glow dark mode (`#050811`) with vibrant cyan and electric blue accents.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.17 or higher recommended)
- `npm` (or `pnpm` / `yarn`)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ImalshaAnu/peak_tech.git
   cd peak_tech
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).
